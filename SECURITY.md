# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

This project is a curated list of educational links. It does not contain application code, user authentication, or data processing logic.

If you believe you have found a security vulnerability related to this repository:

1. **Do not** open a public GitHub Issue.
2. Send a description of the issue to the repository maintainers via email or GitHub's private vulnerability reporting feature at:
   https://github.com/juninmd/Best-websites-a-programmer-should-visit/security/advisories

Please include:
- A description of the issue
- Steps to reproduce (if applicable)
- Any relevant context

We will acknowledge receipt within 48 hours and provide a timeline for a fix.

## Scope

Security concerns relevant to this project include:
- Malicious or unsafe links in the curated list
- Compromised maintainer accounts
- Unauthorized modifications to repository contents

Out of scope:
- Vulnerabilities in the listed third-party websites themselves (report those to the respective site owners)

## Preferred Languages

We prefer all communications in English.
